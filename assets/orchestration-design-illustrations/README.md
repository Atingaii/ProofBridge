# Orchestration design illustrations

Original AI-generated artwork for the public ProofBridge engineering article.
Generated on 2026-09-11 with the built-in image generation tool, guided by
[Ian Xiaohei Illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations)
by Ian, skill revision `91b560849e8f883922cc2fa8a358a668caa94105`.
Skill license and attribution notice are preserved alongside these originals.
No bundled example artwork was copied into the public article.

- `01-collaboration.png`: stitching and checking one shared task booklet.
- `02-shared-workspace.png`: handing over a single key at one workbench.
- `03-review-tradeoff.png`: finding a crooked chair leg, at a cost in time.
- `04-accounting.png`: regrouping the same work without changing its substance.
- `04-accounting-draft.png`: retained original before correcting the label from
  a literal count to the intended accounting metaphor; not a published asset.

White background, fine black pen outlines, deadpan black characters carrying out
physical actions, sparse blue/orange Chinese labels. The illustrations are
metaphors, not quantitative diagrams. Actual stage counts remain in accessible
HTML. Public delivery copies live in `frontend/public/article-assets/orchestration-design/`.
